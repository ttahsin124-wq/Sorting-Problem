## 📖 About

This repository is my personal LeetCode problem-solving log. Every time I solve a problem on LeetCode, it's automatically pushed here by **[LeetSync](https://github.com/)**, complete with **runtime** and **memory usage** stats straight from the judge.

Think of it as a running diary of my journey through arrays, sorting, searching, and everything in between — one commit at a time.

---

## 🚀 How It Works

1. Solve a problem on [LeetCode](https://leetcode.com).
2. **LeetSync** picks it up and creates/updates a folder here automatically.
3. Each folder is named `<problem-number>-<problem-slug>` and contains my accepted solution.
4. Runtime and memory benchmarks are recorded right in the commit history — no manual copy-pasting required.
